# WirthMagePWA

WirthMagePWA は、CardWirth 向けに画像形式・サイズ・色深度などを一括変換できる PWA (Progressive Web Apps) です。ブラウザ上で動作し、インストール不要で手軽に利用できます。インストールしておくと、一度読み込んだあとはオフラインでも利用可能です。

## 動作環境

最新の Google Chrome または Microsoft Edge、その他 File System Access API に対応したPC版ブラウザで動作します。

## 使い方

1. 「ファイル選択」ボタンで変換したい画像を追加
2. 出力サイズと拡大オプションを設定
3. 出力形式や減色・透過・縁取りオプションを選択
4. 「実行」ボタンを押すと、フォルダ選択ダイアログが表示されます
5. 保存先フォルダを選択すると、変換が開始され、進捗ダイアログが表示されます
6. 完了すると指定フォルダに変換後ファイルが保存されます

## 画像の取り扱い

入力された画像はブラウザ上で処理しており、どこにも送信していません。今後も送信することはありませんし、ユーザーを追跡することもありません。

WirthMagePWA で変換された画像に対して、WirthMagePWA 作者・字見明 (AzamiHaru または AzamiHaruCat) は何の権利も主張せず、何の責任も負いません。
